# 🏥 HealthMate – Healthcare Management System

**HealthMate** is a web-based healthcare management system designed to simplify and organize personal health data. It provides **centralized health records**, **structured doctor–patient interaction**, **multi-language support**, and **automated notifications** to improve healthcare accessibility and efficiency.

---

## ✨ Key Features
- 🗂️ Centralized digital health records  
- 👨‍⚕️ Doctor recommendations and structured communication  
- 🌐 Multi-language user interface  
- 📩 SMS and Email notifications using Twilio  
- 🔐 Secure user authentication and role-based access  
- 📱 Works without wearables or external devices  

---

## 🛠️ Tech Stack
- 🎨 **Frontend:** HTML, CSS, JavaScript  
- ⚙️ **Backend:** PHP (XAMPP – Apache Server)  
- 🗄️ **Database:** MySQL  
- 📡 **Notifications:** Twilio SMS & Email API  

---

## 🚀 How to Run the Project
1. Install **XAMPP**
2. Place the project folder inside `htdocs`
3. Start **Apache** and **MySQL** from XAMPP Control Panel
4. Create the database using **phpMyAdmin**
5. Run the project at:  
   👉 `http://localhost/healthmate/`
